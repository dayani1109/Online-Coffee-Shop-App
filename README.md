# ☕ Shadow Coffee Shop – Mobile Ordering App

## 📌 Project Overview

**Shadow Coffee Shop** is a modern Android mobile application designed to provide a seamless coffee ordering experience for users. The app allows customers to browse drinks, view details, and place orders through a clean and intuitive interface.

This project was developed as part of the **Mobile Application Development (MAD) module at SLIIT**, focusing on UI/UX design principles and Android application development.

The application was first designed in **Figma** and then implemented as a fully functional Android app using Android Studio.

---

# 🎯 Project Purpose

The main goal of Shadow Coffee Shop is to simplify the coffee ordering process by:

* Reducing time spent ordering in-store
* Providing a smooth mobile-first experience
* Offering a user-friendly interface for quick navigation
* Enhancing customer convenience through digital ordering

# 🚀 How to Run the Project

## 📌 Prerequisites

Make sure you have installed:

* Android Studio (latest version recommended)
* Java JDK 17+
* Android SDK
* Git

---

## 📥 Clone Repository

```bash id="k8p1aa"
git clone <repository-url>
```

---

## 📂 Open Project

1. Open **Android Studio**
2. Click on **Open Existing Project**
3. Select the cloned project folder
4. Wait for Gradle sync to complete

---

## ▶️ Run Application

1. Connect an Android device or start an emulator
2. Click **Run ▶️** in Android Studio
3. Select your target device
4. The app will build and launch automatically
